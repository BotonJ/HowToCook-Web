# HowToCook 菜谱技能

程序员做饭指南，支持搜索 500+ 菜谱，智能推荐，偏好学习。

## 数据源

| 数据源 | 数量 | 特点 |
|--------|------|------|
| howtocook | 361道 | 程序员风格、精确量化、步骤带公式 |
| 随便做 | 140道 | 节目片尾、简易版/进阶版双步骤 |
| 金谷园 | 1道 | 饺子馆招牌甜品 |

## 筛选维度

| 维度 | 字段 | 值 |
|------|------|-----|
| 分类 | category | 荤菜/素菜/水产/早餐/主食/汤粥/甜点/饮品/调料/半成品 |
| 难度 | difficulty | 1-5 星 |
| 菜系 | cuisine | 川/粤/鲁/湘/东北/西北/苏/浙/闽/徽/京/客家/日式/韩式/东南亚/西式/家常 |
| 烹饪方式 | cooking_method | 炒/炖煮/蒸/烤/炸/凉拌/烘焙/饮品 |
| 时间 | cook_time | quick(<15m)/medium(15-30m)/long(30-60m)/slow(>60m) |
| 辣度 | tags.spicy | true/false |
| 过敏原 | tags.allergens | 花生/海鲜/麸质/乳制品/鸡蛋/大豆 |

## 偏好系统

首次使用时通过问卷初始化口味偏好。后续每次浏览、收藏、制作都会自动积累偏好权重。

偏好文件：`profile.json`（与 index.json 同级）

### 偏好维度
- **硬性约束**：过敏原、饮食限制（素食/清真）、不喜欢的食材 → 直接过滤
- **软性偏好**：菜系、烹饪方式、时间、难度、食材 → 权重排序

### 权重更新
| 行为 | 权重变化 |
|------|---------|
| 做了 | +0.10 |
| 收藏 | +0.07 |
| 浏览 | +0.02 |
| 跳过 | -0.03 |
| 不喜欢 | -0.15 |

权重每天衰减 5%，最近偏好权重更高。

## 文件说明

**运行时（skill 包核心，菜谱数据走 API）：**

- `SKILL.md` — 技能入口
- `schema.py` — 枚举定义、映射规则、标签提取
- `parser.py` — 菜谱解析器（`read_recipe_file` 已弃用，详情走 API）
- `search.py` — 搜索引擎（API 优先 + 本地 fallback，集成偏好）
- `mcp_tools.py` — MCP 工具封装（HTTP API 调用，供代理直接使用）
- `http_client.py` — 共享 HTTP 客户端（统一 `API_BASE` 与 GET 请求）
- `planner.py` — 购物清单 / 一周菜单 / 时间预算推荐（API 优先）
- `profile.py` — 偏好管理（初始化/更新/衰减）
- `questionnaire.json` — 初始化问卷（跨平台通用）
- `index.json` — 菜谱索引（本地 fallback 缓存，详情不依赖它）

**构建工具（仅开发/构建用，不进用户分发包）：**

- `scripts/indexer.py` — 索引生成器：从仓库根 `dishes/` markdown 生成 `index.json`。普通用户包不含 `dishes/`，也不会运行它。

## 输出格式

返回菜谱时附带网站链接，用户可点击查看完整 HTML 页面（含图片、步骤详情）。

格式：
```
🍳 {菜名} | {难度星级} | {烹饪时间}
分类：{category} · 菜系：{cuisine} · 烹饪：{cooking_method}
食材：{完整食材列表}
标签：{tags}

【步骤】
{完整操作步骤（编号）}

【附加内容】
{技巧、注意事项、可用替代食材等}

👉 https://howtocook.cn/recipe/{id}
```

示例：
```
🍳 葱油 | ★★★☆☆ | 30分钟
分类：调料 · 菜系：家常 · 烹饪：其他

【食材】
主料：油 200g、葱 80g、姜 20g、料酒 10ml、洋葱 150g、开洋 50g
可选：香菜

【步骤】
1. 开洋泡入 50 度温水中，加入 10ml 料酒去腥，泡 10 分钟后取出沥干水分
2. 葱、香菜洗净，切成 5cm 长的段，擦干表面水份
3. 洋葱切成丝，在锅里用热水煮 5 分钟，取出沥干水份
4. 姜去皮，切成片
5. 锅里倒入全部油，放入上述预处理好的材料，开中小火炸 20 分钟

【附加内容】
- 渣后的开洋葱渣也可以食用，葱油可以滤掉这些料渣，也可以保留
- 开洋可以极大提升葱油鲜香，并增加鲜甜风味

👉 https://howtocook.cn/recipe/howtocook/%E8%91%B1%E6%B2%B9
```

规则：
- `id` 取自 index.json 的 `id` 字段
- URL 中的中文需要 encode（如 `葱油` → `%E8%91%B1%E6%B2%B9`）
- 难度用 ★ 和 ☆ 表示（如难度 3 → `★★★☆☆`）
- 步骤用编号 `1.` `2.` 列出，保留原文中的用量和时间数据
- 附加内容非必须，无附加内容时省略该节
- 多个结果时每个菜谱独立一段，段与段之间空一行

## 食材智能（Epicure）

基于 1,790 种食材的 300 维嵌入模型，支持：

| 功能 | 触发示例 | 返回 |
|------|---------|------|
| 食材配对 | "什么和鸡肉搭配" | Top-10 最相似食材（含中文名 + 相似度） |
| 食材替代 | "没有酱油用什么替代" | Top-5 替代品 |
| 风味探索 | "把鸡肉往东南亚方向旋转" | SLERP 旋转后的食材推荐 |
| 烹饪群落 | "鸡肉属于什么风味群" | 最接近的烹饪模式 |

菜系方向：East_Asian, Southeast_Asian, South_Asian, Mediterranean, Western_Atlantic, Eastern_European, Latin_American
