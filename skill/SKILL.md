# HowToCook 菜谱技能

程序员做饭指南，支持搜索 500+ 菜谱，智能推荐，偏好学习。

## 数据源

| 数据源 | 数量 | 特点 |
|--------|------|------|
| howtocook | 361道 | 程序员风格、精确量化、步骤带公式 |
| 随便做 | 140道 | 节目片尾、简易版/进阶版双步骤 |
| 金谷园 | 1道 | 饺子馆招牌甜品 |

## 偏好系统

首次使用时通过问卷初始化口味偏好。后续每次浏览、收藏、制作都会自动积累偏好权重。

偏好文件：`profile.json`（与 index.json 同级）

### 偏好维度
- **硬性约束**：过敏原、饮食限制（素食/清真）、不喜欢的食材 → 直接过滤
- **软性偏好**：菜系、烹饪方式、时间、难度、食材 → 权重排序

### 权重更新
| 行为 | 权重变化 |
|------|---------|
| 做了 | +0.10 |
| 收藏 | +0.07 |
| 浏览 | +0.02 |
| 跳过 | -0.03 |
| 不喜欢 | -0.15 |

权重每天衰减 5%，最近偏好权重更高。

## 文件说明

- `SKILL.md` — 技能入口
- `schema.py` — 枚举定义、映射规则、标签提取
- `indexer.py` — 索引生成器
- `parser.py` — 菜谱解析器
- `search.py` — 搜索引擎（API 优先 + 本地 fallback，集成偏好）
- `mcp_tools.py` — MCP 工具封装（HTTP API 调用，供代理直接使用）
- `profile.py` — 偏好管理（初始化/更新/衰减）
- `questionnaire.json` — 初始化问卷（跨平台通用）
- `index.json` — 菜谱索引
- `config.json` — 数据源配置

## 输出格式

返回菜谱时附带网站链接，用户可点击查看完整 HTML 页面（含图片、步骤详情）。

格式：
```
🍳 {菜名} | {难度星级} | {烹饪时间}
分类：{category} · 菜系：{cuisine} · 烹饪：{cooking_method}
食材：{完整食材列表}
标签：{tags}

【步骤】
{完整操作步骤（编号）}

【附加内容】
{技巧、注意事项、可用替代食材等}

👉 https://howtocook.cn/recipe/{id}
```

示例：
```
🍳 葱油 | ★★★☆☆ | 30分钟
分类：调料 · 菜系：家常 · 烹饪：其他

【食材】
主料：油 200g、葱 80g、姜 20g、料酒 10ml、洋葱 150g、开洋 50g
可选：香菜

【步骤】
1. 开洋泡入 50 度温水中，加入 10ml 料酒去腥，泡 10 分钟后取出沥干水分
2. 葱、香菜洗净，切成 5cm 长的段，擦干表面水份
3. 洋葱切成丝，在锅里用热水煮 5 分钟，取出沥干水份
4. 姜去皮，切成片
5. 锅里倒入全部油，放入上述预处理好的材料，开中小火炸 20 分钟

【附加内容】
- 渣后的开洋葱渣也可以食用，葱油可以滤掉这些料渣，也可以保留
- 开洋可以极大提升葱油鲜香，并增加鲜甜风味

👉 https://howtocook.cn/recipe/howtocook/%E8%91%B1%E6%B2%B9
```

规则：
- `id` 取自 index.json 的 `id` 字段
- URL 中的中文需要 encode（如 `葱油` → `%E8%91%B1%E6%B2%B9`）
- 难度用 ★ 和 ☆ 表示（如难度 3 → `★★★☆☆`）
- 步骤用编号 `1.` `2.` 列出，保留原文中的用量和时间数据
- 附加内容非必须，无附加内容时省略该节
- 多个结果时每个菜谱独立一段，段与段之间空一行
